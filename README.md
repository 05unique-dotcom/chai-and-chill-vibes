# Chai & Chill Landing

Create a beautiful, responsive Indian Street Food 

landing page called "Chai & Chill" with these sections:



1. Hero section - Big heading "Chai & Chill" with 

tagline "Your favorite street food, one sip away" 

and a CTA button "Order Now". Warm cozy background.



2. Featured Items section - Cards for:

- Cutting Chai ☕

- Vada Pav 🍔  

- Samosa 🥟

- Poha 🍛

Each card has name, description, price in rupees, 

and "Add to Cart" button.



3. About section - "Made with love since 1985, 

straight from Mumbai streets to your heart"



4. Footer with social links



Design: Warm orange, brown, cream color palette. 

Cozy and appetizing feel. CSS animations on hero. 

Mobile responsive. Modern clean design.
